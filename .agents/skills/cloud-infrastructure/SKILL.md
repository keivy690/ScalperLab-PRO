# Infraestrutura e Cloud Computing

- Confirme necessidade de rede/serviço externo e dependências operacionais antes de adicionar recursos cloud ao desktop local.
- Defina segmentação, DNS/TLS, identidade de workload, rotação de segredos, armazenamento e retenção com menor privilégio.
- Evite expor MT5, serviços locais, bancos ou endpoints de execução em interfaces públicas.
- Inclua limites e alertas de custo, disponibilidade e quotas de provedores; falha cloud não deve ser confundida com mercado parado.
- Produza configurações reproduzíveis e reversíveis. Não aplique infraestrutura de produção sem autorização específica.
